# Instrucción de Análisis y Respuestas

## Instrucción Registrada
**Fecha:** Fecha actual
**Solicitante:** Usuario de la plataforma
**Contexto:** Interacción durante desarrollo/consulta

## Instrucción Específica
> "No muestres código fuente en los análisis y respuestas que des."

## Interpretación y Aplicación
Esta instrucción debe aplicarse en todas las interacciones subsiguientes:

### Reglas de Cumplimiento:
1. **Análisis conceptual**: Solo proporcionar análisis conceptuales y explicaciones en texto plano
2. **Referencias técnicas**: Si es necesario mencionar estructuras de archivos o referencias técnicas, hacerlo en términos generales sin mostrar contenido de código
3. **Herramientas de desarrollo**: Las herramientas (lectura de archivos, búsquedas, etc.) se ejecutarán internamente sin mostrar el código fuente en las respuestas
4. **Sugerencias de cambios**: Si se necesitan sugerir cambios, describirlos en términos de funcionalidad y propósito
5. **Implementaciones**: Cualquier implementación se realizará utilizando las herramientas apropiadas sin exponer el código en las respuestas de análisis

### Ejemplos de Aplicación:
- ✅ **Correcto**: "La función de validación necesita ajustarse para manejar casos extremos"
- ❌ **Incorrecto**: "En el archivo validator.py, la línea 45 debería cambiarse por: `if value > threshold:`"
- ✅ **Correcto**: "Se recomienda agregar manejo de errores en el módulo de conexión"
- ❌ **Incorrecto**: Mostrar bloques de código de ejemplo

### Excepciones:
- Solo cuando sea estrictamente necesario para demostración técnica y con autorización explícita
- En contextos educativos donde la instrucción lo permita explícitamente

## Ámbito de Aplicación
Esta instrucción aplica a:
- Todas las interacciones de análisis
- Respuestas a consultas técnicas
- Revisiones de código
- Sugerencias de implementación
- Documentación generada

## Registro de Cumplimiento
Cada interacción debe verificar el cumplimiento de esta instrucción antes de generar cualquier respuesta.

## Historial de Revisiones
- **Fecha inicial**: Instrucción registrada e implementada
- **Próxima revisión**: Mantener vigente hasta nueva instrucción
